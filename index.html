Al-Fatyan Scout RAG System — نظام محاضر الفتيان

A fully local, offline RAG system for querying Arabic scout troop meeting minutes. Combines section-aware chunking (per meeting, split on the decisions header for longer records), local multilingual embeddings, and a local LLM to answer questions in Arabic or English — every answer cites the exact meeting number and date, and the system explicitly says when it can't find an answer instead of guessing. Ships with a Streamlit chat UI.

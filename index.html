Work

Nine projects. The numbers match the citations above.

  1. 1

    Mizan ميزان

    Commercial product, private code

    A question-answering engine over Jordanian tax and regulatory documents, built for accounting and tax firms. Every answer cites the article, page and dated version it came from, or says the sources don't cover the question without calling the model at all.

    A verifier checks each generated answer before it is shown: citations must be in range and every number must appear in a source. Scanned laws come in through OCR. Each firm's data is isolated in the database schema and the vector layer, and the same Docker image runs hosted or on a client's own server.

    Built with FastAPI, PostgreSQL, Qdrant, multilingual-e5, PaddleOCR, Claude or Ollama, Docker

  2. 2

    WhatsApp inquiry assistant

    Client work, private code

    Answers customer questions on WhatsApp from a company's own data. Built for real-estate developers and adapted for clinics. Claude classifies each message, the relevant facts are pulled from the company's website, spreadsheets or a read-only database, and a reply is drafted in Arabic or English from those facts only.

    A guard checks every number and date against the source, and nothing is sent until a staff member approves it. Bookings, discounts and unpublished prices skip the draft and go straight to a person. Each client runs as an isolated instance, with an end-to-end test proving one client's messages never reach another's database.

    Built with FastAPI, WhatsApp Cloud API, Claude structured output, pytest

  3. 3

    Muyassar ميسّر

    In progress, not public yet

    Explains people's rights under published Jordanian laws in plain Arabic, starting with personal data protection and the rights of persons with disabilities. Every statement links to the article it comes from, and the cited text opens beside the answer.

    Laws are chunked on article boundaries and retrieval is reranked before Claude writes. A known-answer benchmark measures how often the right article comes back first and in the top five, and those numbers are shown on the page. It explains the text; it does not give personal legal advice.

    Built with Python, RAG, reranker, Claude Sonnet, recall@k evaluation, RTL interface

  4. 4

    Arabic OCR with CRNN and CTC

    Open source

    A text-line recognizer for Arabic built from scratch, with no pretrained weights and no external OCR engine. A CNN feeds a two-layer BiLSTM trained with CTC loss, so no character-level alignment is needed.

    A generator renders hundreds of thousands of Arabic sentences in random fonts to train it, and an ink-projection step splits scanned pages into lines before recognition. The whole thing is sized to train on a 4GB laptop GPU.

    Built with PyTorch, CRNN, CTC loss, computer vision

    Source code on GitHub

  5. 5

    Meeting RAG pipeline

    Open source

    Turns Arabic and English video meetings into a searchable knowledge base that grows with each meeting, with every stage running on your own machine.

    Audio is diarized to know who spoke when, transcribed with Whisper, embedded with a multilingual model and stored in a local Qdrant instance. A local LLM answers questions from the retrieved chunks or writes full meeting minutes. No cloud API keys anywhere.

    Built with Whisper, pyannote-audio, Qdrant, Ollama (Qwen2.5)

    Source code on GitHub

  6. 6

    Al-Fatyan Scout RAG نظام محاضر الفتيان

    Open source

    A fully offline system that answers questions over a scout troop's Arabic meeting minutes. Every answer cites the meeting number and date it came from, and says plainly when it can't find one.

    Records are split on their decisions header so long meetings stay coherent. A local multilingual embedding model and a local LLM handle Arabic and English, behind a Streamlit chat interface.

    Built with ChromaDB, Sentence-Transformers, Ollama (Qwen2.5), Streamlit

    Source code on GitHub

    A FastAPI backend runs the scoring and evaluation models, and a Next.js frontend presents them.

    Built with FastAPI, Next.js, scikit-learn

    Source code on GitHub

  8. 8

    Diabetes prediction model

    Open source

    A classifier trained on the Pima Indians Diabetes dataset and tuned for screening instead of raw accuracy.

    Missing clinical values are mean-imputed, hyperparameters are searched with GridSearchCV, and the decision threshold is lowered from 0.5 to 0.25. That trades some false alarms for fewer missed positives, which is the trade a screening tool should make.

    Built with scikit-learn, random forest, GridSearchCV

    Source code on GitHub

  9. 9

    KNN shape classifier with Arduino

    Open source

    A real-time vision pipeline that goes from camera to physical hardware. Each frame is converted to grayscale, run through Canny edge detection and classified as a square or a circle by a KNN model.

    The prediction is sent over serial to an Arduino, which lights a green or yellow LED to match. Classical computer vision and a distance metric, running live.

    Built with OpenCV, scikit-learn, KNN, Arduino, serial I/O

    Source code on GitHub
